# C03 - Git: lưu một thay đổi và gửi vào fork

Dành cho giảng viên/dev; không gửi trước vào client challenge.

```text
Fork qua giao diện GitHub; clone URL fork; sửa README; git add README.md; git commit -m "First student commit"; git push origin HEAD. Xác nhận origin thuộc tài khoản học viên và hash commit remote bằng local.
```

## Đáp án kiểm tra hiểu

1. Commit thành công nhưng chưa push. Bạn khác thấy commit trên GitHub chưa?

Đáp án: Chưa

- Chưa: Đúng: commit mới còn ở local.
- Đã thấy ngay: Commit local chưa gửi tới remote.
- Phải xóa rồi clone lại: Chỉ cần push khi remote đúng.
