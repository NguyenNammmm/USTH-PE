# Bài mẫu tương tác · Từ phương trình đến hồi quy

Đây là **một ví dụ tham khảo** cho cách thiết kế bài tập Linear Algebra cho ML tại USTH. Bài dùng dữ liệu giả định về điện năng.

## Triết lý thiết kế

- **Một vấn đề xuyên suốt.** Ba câu nối tiếp nhau. Sinh viên dựng đường, đọc residual tại một điểm, rồi so sánh MSE trên cả tập.
- **Một quyết định mỗi màn.** Chọn đáp án để xem hệ quả trên biểu đồ. Bấm **Kiểm tra** để nhận phản hồi về cách suy luận.
- **Giải thích rồi vận dụng.** Hoạt cảnh cho thấy cách dùng chính đường vừa chọn để dự đoán điện năng. Hai câu cuối cho sinh viên tự dự đoán và đối chiếu số đo.

## Cách mở

Tải [bai-tap.html](bai-tap.html) và mở bằng Chrome hoặc Edge. CSS, JavaScript và dữ liệu nằm trong HTML, nên bài chạy ngoại tuyến. Đặt [loi-giai.md](loi-giai.md) cùng thư mục để mở lời giải và nguồn tham khảo từ bài.
