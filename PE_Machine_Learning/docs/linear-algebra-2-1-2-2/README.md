## Thử hai bài

- **Bài 2.1.** Kéo thanh để đổi a, giữ b = 2. So sánh hai kết quả trên trục rồi chọn phần tử đơn vị của phép ⋆.
- **Bài 2.2.** Chọn `mod 5` hoặc `mod 8` để xem 2 × 4 dừng ở ô nào trên vòng. Dùng cùng cách đọc phần dư cho 3 × 4 trong `mod 6`.
